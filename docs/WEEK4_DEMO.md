# Week 4 evaluation demo guide

Record a four to five minute walkthrough after reviewing the candidate reference labels. Use the recorded results in `WEEK4_EVALUATION.md` and the final workbook; do not describe development-label agreement as human-validated accuracy. The project uses the own-agent spreadsheet track and evaluates the evidence-review component of the Week 3 Deep Investigation agent.

## Recording setup

```bash
uv run streamlit run app.py --server.address 127.0.0.1 --server.port 8502
```

Open Evaluation, select `evaluation/week4-comparison/report.json`, then inspect individual runs and case evidence. Open the final workbook from `outputs/week4/`. The app displays existing artifacts without making provider calls. Keep `.env`, local SQLite workspaces, provider account pages, and unrelated private windows out of the recording.
